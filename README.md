My First Project!

This project was developed as an introduction to Java programming and object-oriented programming. The main purpose is to apply fundamental programming concepts in practice and develop a better understanding of how they work together in a complete program.

Project Focus
The project focuses on fundamental concepts in the Java programing language, including:
 - Variables and data types
 - Conditional statements and loops
 - Methods
 - Classes and objects
 - Encapsulation using getters and setters
 - Basic object-oriented programming
  
 Technologies
 - Java
 - VS Code
 - Git
 - GitHub

Purpose
The project serves as a foundation for further development and more advanced programming projects as I continue to develop my programming skills.

Status
The current version of the project is complete, but additional features may be added in the future.
